Privacy

What this page records

Short version: no account, no cookie, no tracker id. One hit record per page load, and your address is part of the page URL.

Last updated 23 November 2026

What is stored

Each page load writes one row to a database we run on Cloudflare. The row holds:

Time
Server timestamp, ISO 8601
Path
The page path and its query string — so an address you pasted after ?address= is in this field, truncated at 300 characters
Referrer
The page you came from, if your browser sends one, truncated at 300 characters
Country and city
Provided by Cloudflare from the IP the request arrived on
IP, truncated
IPv4 keeps three octets (203.0.113.x), IPv6 keeps four groups (2001:db8:1:2:x)
User agent
Browser string, truncated at 220 characters
Language, screen size, timezone
Sent by the page for statistics, truncated at 12 / 24 / 60 characters

There is no session id, no device fingerprint and no cookie of any kind. We keep the rows; nothing joins them into a profile of you.

What is sent to other servers

Three kinds of request leave your browser:

  • Public RPC nodes — the address you check is sent to the node that answers the balance query. Those nodes see the address and your IP, the same as any website you visit.
  • DEX Screener — asked for a token price. No address is included.
  • Cloudflare — our hit record above, plus Cloudflare Web Analytics, which reports page views without cookies.

No advertising network, no pixels, no cross-site identifier.

Your wallet

The page never sees a seed phrase or a private key. Signing happens inside your own wallet. We cannot move funds without a signature you approve.

Keeping and deleting

Hit rows stay in the database until we clear old ones; there is no fixed retention promise yet, which we would rather say than invent. Because an address sits in the path field, a row can be matched to an address by search.

To have a row removed, send the address and roughly when you visited to the Telegram contact below.
